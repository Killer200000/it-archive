# IT Archive

Личный статический архив IT-специалиста в стиле **dark/tech vibe**. Сайт работает на GitHub Pages и Netlify без сборщиков — чистый HTML + Tailwind CSS (CDN) + Vanilla JS. Все файлы хранятся на [Archive.org](https://archive.org).

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка сайта, Tailwind через CDN, навигация |
| `style.css` | Дополнительные стили (скроллбар, анимации) |
| `app.js` | Загрузка `data.json`, фильтрация, поиск, рендер карточек |
| `data.json` | Весь контент (записи, разделы, ссылки на архив) |
| `README.md` | Эта инструкция |

## Как добавить новую запись

1. Откройте `data.json`.
2. Найдите массив `"items"`.
3. Добавьте объект со следующими полями:

```json
{
  "id": "win-004",
  "category": "windows",
  "title": "Название файла",
  "subtitle": "Тип файла",
  "description": "Краткое описание...",
  "version": "1.0",
  "size": "4.7 GB",
  "format": "ISO",
  "badge": "ISO",
  "icon": "🪟",
  "hashType": "SHA256",
  "hash": "хэш-файла",
  "downloadUrl": "https://ia.....us.archive.org/.../файл.iso",
  "archiveUrl": "https://archive.org/details/...",
  "dateAdded": "2024-04-01"
}
```

- `category` должен соответствовать одному из разделов: `windows`, `android`, `software`, `games`.
- `hash` — опционально. Если не нужен, кнопка копирования хэша не отобразится.
- `downloadUrl` — прямая ссылка на Archive.org (например, `https://ia800000.us.archive.org/...`).
- `archiveUrl` — страница материала на Archive.org.

4. Сохраните файл. Карточка появится автоматически в соответствующем разделе и на главной.

## Деплой

### GitHub Pages
1. Загрузите файлы в репозиторий.
2. В настройках репозитория (Settings → Pages) выберите ветку `main` и папку `/ (root)`.
3. Сайт будет доступен по адресу `https://<user>.github.io/it-archive/`.

### Netlify
1. Подключите репозиторий к Netlify или загрузите папку вручную.
2. Команда сборки не требуется — статический сайт.
3. Директория для публикации: корень `/`.

## Разделы

- **Главная** — дашборд и последние добавления
- **Windows** — образы ОС, активаторы, системный софт
- **Android** — прошивки, APK, инструменты прошивки
- **Софт** — утилиты администрирования, сети, диагностики
- **Игры** — портативные игры, ретро-хиты, сборники

## Особенности

- Полностью адаптивный дизайн (мобильные устройства, планшеты, десктоп)
- Поиск по названию и описанию во всех категориях
- Копирование MD5/SHA256 хэшей в буфер обмена
- Прямые ссылки на скачивание с Archive.org
- Тёмная тема с неоновыми акцентами
